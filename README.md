# Amol-Sticky-Note-Project
An interactive web application that allows users to create and delete sticky notes on a dashboard. This project is designed to help users organize their thoughts and tasks effectively.

# Features
1. Create Sticky Notes: Users can type a note in the text area and add it to the dashboard with a click of a button.
2. Delete Sticky Notes: Each sticky note has a small delete button (X) to remove it from the dashboard.
3. Alternating Note Colors: Notes alternate between two background colors for better visual distinction.
4. Responsive Design: The layout and styling are clean and visually appealing with proper spacing and alignment.
5. Dynamic Interactions: Built using JavaScript to handle browser events and DOM manipulation

# Technologies Used
- HTML: Markup for structure.
- CSS: Styling and layout design.
- JavaScript: Event handling and DOM manipulation.
